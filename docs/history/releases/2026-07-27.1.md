## Packaging correction

The predecessor calculated all seven payload checksums from Windows CRLF working-tree bytes. Git
stored LF-normalised blobs, so strict validation failed on Linux. The predecessor remains
immutable and is retained for audit history; its manifest was not edited and validation was not
weakened.

Every JSON and JSONL payload in this release contains LF newlines only. Checksums were calculated
after final bytes were written. Replay and production repository loading both passed before
`active.json` was switched.
