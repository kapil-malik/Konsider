# Release 2026-07-21.1

Status: active packaging correction published on 2026-07-21

## Purpose

Release `2026-07-20.2` calculated its declared payload checksums from CRLF working-tree bytes. Git
stored LF blobs, so a fresh Linux checkout received valid JSON content whose bytes did not match
that immutable manifest. Release `2026-07-21.1` corrects packaging without rewriting the earlier
published release.

The corrected manifest points to `2026-07-20.2` as its previous release. Its seven checksummed
payload files contain the same parsed JSON values as the earlier release and differ only in line
endings. Observations, scores, attempts, sources, raw-artifact metadata, sensitivity results,
validation findings, criterion readiness, and scoring method versions are unchanged.

## Portable packaging

`.gitattributes` forces committed release JSON and JSONL files to LF on every platform. The active
manifest checksums those LF bytes, and its release checksum is derived from the corrected file
checksum map. The former release directory remains present and unchanged for history.
