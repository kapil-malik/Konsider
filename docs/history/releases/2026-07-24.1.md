# Release 2026-07-24.1

Status: active, published, immutable

Published: 2026-07-24

This release closes Phase 2D with the stable 91-country complete-case universe. It supersedes the
20-country packaging release `2026-07-21.1`, which remains immutable and recoverable.

## Country and source policy

- Universe: `stable_supported_v1`
- Policy: `complete-case-approved-sources-v1`
- Source audit: `coverage-2026-07-23.6-all-eligible`
- Final list: `data/country-universes/stable-supported-v1.json`
- Homicide production source: World Bank WDI `VC.IHR.PSRC.P5` only

Direct UNODC and UNSD could technically supply fresher observations for Bangladesh, Belarus,
Kuwait, and Saudi Arabia, but their production reuse terms were not sufficiently clear. The four
countries therefore remain excluded because their WDI records fail the unchanged five-year
freshness rule. Eurostat adds none of the residual countries and OECD is not an equivalent
national-total series. No UN, Eurostat, or OECD study adapter remains in the production runtime.

## Consumer changes

The API health, catalog, rankings, comparisons, and country detail routes now consume the 91-country
snapshot without contract-shape changes. The browser adds country-name/ISO search, API-derived
region filtering, visible/total counts, bounded desktop scrolling, and complete mobile cards. The
release label remains visible in the ranking footer and Data & Sources view.

## Local performance verification

Measurements were taken on the Windows development machine after one warm request, with 25 samples
per API route. They are engineering checks, not production service-level objectives.

| Operation | Response bytes | Median | p95 |
| --- | ---: | ---: | ---: |
| Catalog | 15,879 | 17.36 ms | 30.75 ms |
| All-country ranking | 655,670 | 63.26 ms | 93.77 ms |
| Country detail | 9,533 | 17.19 ms | 31.44 ms |
| Two-country comparison | 15,170 | 28.52 ms | 32.41 ms |
| Vite index response | 653 | 15.26 ms | 30.41 ms |

The local start helper reached healthy API and UI endpoints in 11.4 seconds. The production browser
bundle was 257.09 kB (79.16 kB gzip). In the in-app browser, the full desktop table rendered all 91
rows inside a 608 px bounded viewport with 5,704 px scroll content. Country search updated in 73 ms
and the region filter in 213 ms. At 390 × 844, the table was hidden, all 91 complete cards were
present, and searching the final country (South Africa) updated in 117 ms. These measurements do not
justify server pagination, virtualization, a database, or additional caching.

## Known limitations

- UHC remains unavailable for ranking until a sufficiently fresh official edition is published.
- Infrastructure remains experimental and represents only its three documented components.
- Homicide comparisons retain legal-definition and reporting-capacity cautions.
- Ignored raw third-party bytes are required for full offline replay.
- Country-count changes require a deliberate future source and data review.
