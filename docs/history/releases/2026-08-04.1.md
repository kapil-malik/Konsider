# Release 2026-08-04.1

Status: active, product-ready, immutable

Published and activated: 2026-08-04

This is the first release-schema-5.1 publication and the final Phase 6 artifact. It preserves all
ranking payload bytes from `2026-07-29.2` and adds a checksummed sibling Opportunity Filter bundle.

The manifest and payloads under `data/releases/2026-08-04.1` are authoritative. The build manifest
under `data/reports/phase6i-2026-08-04` records accepted upstream and final payload checksums.

## Compatibility

The API contract remains `konsider-api-2.0`; Opportunity Filter fields and the catalog route are
additive. No filter selected preserves the prior ranking result. Release-5.0 remains explicitly
loadable for history, but only 5.1 releases can bind active Opportunity Filters.

## Rollback boundary

Do not modify this release. To roll back, validate the target immutable release, atomically update
`active.json` with both its release ID and matching schema version, restart the API, and verify its
health identity. Rolling back to `2026-07-29.2` intentionally returns an empty OFC catalog.

See the [Phase 6 closure report](../phase6-closure-report.md) for decisions, state counts, tests,
performance, dependencies, and limitations.
