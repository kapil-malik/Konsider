# Release 2026-07-26.3

Status: immutable, superseded packaging-invalid release

This release cannot be activated from a Linux or other LF-normalised Git checkout. Its seven
`file_checksums` values were calculated from pre-normalised Windows CRLF bytes, while Git committed
LF bytes. Strict checksum validation therefore correctly rejects the committed payloads. The
release directory remains immutable; the corrected, semantically identical successor is
[`2026-07-27.1`](2026-07-27.1.md).

Release `2026-07-26.3` keeps the stable 91-country universe and adds three production-ready
criteria: political stability, rule of law, and established immigrant presence. It contains 819
observations and 819 canonical scores across nine published criteria. Eight criteria are enabled;
UHC remains visible but non-ready because its 2021 observations are stale.

## Added sources and methods

- Political stability and rule of law use the World Bank Worldwide Governance Indicators 2025
  workbook, 2024 estimates. Published standard errors and 90% confidence bounds are retained.
- Established immigrant presence uses World Bank WDI `SM.POP.TOTL.ZS`, reference year 2024, with
  UN Population Division upstream attribution.
- All three use fixed, versioned broad-band transformations. Immigrant presence is explicitly a
  preference property, not a universal quality or a proxy for acceptance, integration, or visas.

## Validation

- 91/91 valid observations for each new criterion.
- Eight product-ready criteria and one explicitly non-ready criterion.
- Zero validation errors; the 91 blockers are the expected stale UHC observations.
- Political-stability/rule-of-law average-rank Spearman correlation is 0.7295, below the 0.90
  review threshold. Both remain separately visible and the diagnostic is retained.
