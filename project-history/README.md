and one-off research scripts. It is intentionally separate from current product documentation,
runtime code, immutable releases, and operational scripts.

  structured-assessment prompt pack.
- [Phase 6](phases/phase-6/00_README.md) — original career and engineering-education opportunity
  plan and prompt sequence.

Current, authoritative documentation lives in [`docs`](../docs/README.md). Historical material may
describe an earlier release or directory layout and must not override current contracts.
