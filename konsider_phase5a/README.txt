Konsider Phase 5A deliverables

1. phase5a_framework.md
   Authoritative research framework, classifications, ordered master list,
   first two batches, gates, statuses, reason codes and hand-offs.

2. phase5a_master_research_list.json
   Machine-readable ordered list of all 84 candidate criteria.

3. phase5a_master_research_list.csv
   Flat companion list for quick review and filtering.

4. phase5a_research_record.schema.json
   Draft 2020-12 JSON Schema for Phase 5B/5C/5E research records.

The framework does not approve new sources or relax current production
guardrails. It separates the 82/91 feasibility threshold from the default
91/91 production-completeness baseline.
