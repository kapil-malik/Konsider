# Konsider Phase 5 — Criteria Expansion and Source Feasibility

## Purpose

Phase 5 expands Konsider from the current five enabled ranking criteria toward a balanced portfolio of approximately 10–15 production-ready criteria.

It preserves the current evidence-first principles: authoritative sources, explicit production reuse rights, adequate coverage of the stable 91-country universe, acceptable freshness, comparable definitions, deterministic processing, replayability, and explicit rejection evidence.

## Sub-phases

- **5A — Research framework and prioritisation**
  Owner: Web ChatGPT

- **5B — Lightweight screening of all 84 criteria**
  Owner: Desktop ChatGPT Work, or Web ChatGPT

- **5C — Deep source-feasibility research**
  Owner: Desktop ChatGPT Work, in batches of 12–15

- **5D — Generic deterministic feasibility-probe framework**
  Owner: Codex

- **5E — Candidate-specific measured probes**
  Owner: Codex

- **5F — Portfolio selection and guardrail review**
  Owner: Web ChatGPT

- **5G — Production implementation of approved criteria**
  Owner: Codex

- **5H — Closure report and roadmap renumbering**
  Owner: Codex, reviewed by Web ChatGPT

## Recommended order

Run 5A, then 5B. Review both before finalising the first 5C batch. Start 5D only after 5C reveals recurring source and reporting patterns. Run 5E only for approved promising candidates. Complete 5F before any production implementation.
